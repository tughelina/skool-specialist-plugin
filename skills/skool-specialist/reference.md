# Skool About-Page · Discovery · Google-SEO — Research base (as of 2025/2026)

> Sourced reference for the skool-specialist skill.
> ⚠️ Honesty: Skool's exact Discovery algorithm is NOT fully officially documented. Officially confirmed (Skool Help Center) are only **Member Growth · Engagement · Retention**. Everything about keyword weighting/order is ecosystem-derived, partly speculative.

## 1) About page = sales page (order)
1. **Cover image / VSL** at top — clear in ~5 sec who it's for. Short video sales letter lifts conversion (face + one transformation line).
2. **Hook / first lines** = audience pain point; no greeting, no company history.
3. **Headline with transformation** — what they *become/have* after.
4. **Benefits as outcomes**, not features.
5. **Social proof** — testimonials, member count, success stories (sensitive niche: real empathetic voices, not income figures). Never fabricate.
6. **Visual preview** — mockups (modules, community, rituals).
7. **Price framing** — value/transformation before price. Ad→free group: no price/income claims.
8. **ONE CTA.**
Free-community benchmark: ~25–30% conversion (practitioner guideline).

## 2) Skool Discovery ranking
**Official (Skool Help):** ranking = Member Growth + Activity + **Retention** (most important). Per category, not global. New groups rank lower, rise with age. Minimum threshold to appear; description + About + images + cover required. Anti-gaming: manual review; points-farming → **delisting**. Removing lurkers does nothing. **Growth Boost** feature for visibility.

**2026 (announced, Q2 rollout — verify):** up to **11 Community Keywords** (biggest new findability lever); new search (~Apr 2026) relevance>size; Trending homepage (~May 2026); algorithm rewards engagement quality; new categories incl. AI.

## 3) Google SEO for public Skool pages
- Group name = H1/SEO title: keyword over brand, 50–60 chars.
- About text: secondary keywords natural (no stuffing). Formula: who + what it does + benefit + CTA.
- Custom domain/forwarding → trust.
- Backlinks (YouTube desc, newsletter, blog, LinkedIn) = strongest lever besides title.
- Weekly SEO posts: keyword-rich H1 + keyword in first paragraph + H2/H3.
- Classroom: keyword-rich lesson titles + transcripts (Google doesn't index video).
- Keyword choice: what does the ideal member literally type into search?

## 4) Do's & Don'ts
**Do:** About as sales page (Hook→Transformation→Proof→1 CTA) · fill all required fields · 11 keywords = exact search terms · descriptive keyword group name · optimize retention/interaction.
**Don't:** no points-farming (delisting) · no feature lists · no keyword stuffing · no multiple CTAs · no price/income claims on ad→free · don't remove lurkers.
